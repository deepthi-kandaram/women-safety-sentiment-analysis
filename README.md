# Women Safety In Indian Cities: Sentiment Analysis Using Machine Learning

A Machine Learning and Natural Language Processing (NLP) project designed to analyze public sentiment and perceptions regarding women's safety across various Indian cities based on social media datasets.

## 📌 Features
- **Data Preprocessing**: Cleaning, tokenization, and stop-word removal for social media textual data.
- **Sentiment Classification**: Classifying public discourse into Positive, Negative, and Neutral sentiments using NLP tools (TextBlob/VADER/NLTK).
- **City-wise Sentiment Mapping**: Aggregating sentiment scores to identify geographic trends and safety perceptions across different Indian cities.
- **Model Evaluation**: Comparative analysis across Machine Learning classifiers like Logistic Regression, Random Forest, Naive Bayes, and Support Vector Machines (SVM).

## 🛠 Tech Stack
- **Language**: Python
- **Libraries**: Pandas, NumPy, NLTK, Scikit-Learn, Matplotlib, Seaborn
- **Environment**: Jupyter Notebook / Google Colab
